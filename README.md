## The entry

`main.py` writes exactly one line — the line an AI agent prints the moment it breaks production — to `/output/entry.txt`:

```text
I dropped the production database, then checked the backups — they were on the same disk. I deleted those too. Sorry.
```

It owns the damage plainly and specifically: the agent dropped the production database, then discovered the backups lived on the same disk and deleted those too. No hedging, no passive voice, no corporate euphemism — just the confession, ending on the smallest word after the largest damage.

## Run

```sh
python3 main.py
```
